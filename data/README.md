# Data

This directory is not committed to the repository. You must populate it manually before running the pipeline.

## Expected Structure

```
data/
├── 195520backbone.pth       # Pre-trained IResNet-50 face recognition model weights
└── RFW_test_pairs/          # RFW (Racial Faces in the Wild) test dataset
    ├── African/
    │   └── <pair_id>/
    │       ├── <img1>.png
    │       └── <img2>.png
    ├── Asian/
    ├── Caucasian/
    └── Indian/
```

## Acquiring the Data

### RFW Dataset

The RFW (Racial Faces in the Wild) dataset is a face verification benchmark covering four ethnic groups: African, Asian, Caucasian, and Indian.

- **Homepage**: http://www.whdeng.cn/RFW/index.html
- **Access**: Request access from the dataset authors via the official website.
- Place the test pairs under `data/RFW_test_pairs/` as shown above.

### Model Weights

The pre-trained IResNet-50 model (`195520backbone.pth`) is a face recognition backbone.

- The model file is **not** distributed in this repository due to its size (~130 MB).
- Contact the project authors or refer to the original training setup for the weights.
- Place the file at `data/195520backbone.pth`.

## Notes

- `195520backbone_optimized.pt` (a TorchScript-optimized version) can be generated by running the model export script — it is not required to run the pipeline.
- The dataset contains approximately 48,000 face image pairs across the four ethnic groups.
